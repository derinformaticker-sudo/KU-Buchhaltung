# Lokale Laufzeitdaten

Dieser Ordner ist für lokale Anwendungsdaten reserviert. Seine Inhalte werden außer dieser Beschreibung nicht versioniert. Hier keine Beispieldateien mit echten personenbezogenen Daten einchecken.

Der spätere Speicherort wird konfigurierbar. Sicherungen müssen Datenbank und Dokumente einschließen und außerhalb dieses Ordners aufbewahrt werden.
